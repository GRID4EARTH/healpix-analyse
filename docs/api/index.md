# API reference

The public API of `healpix_analyse`, grouped by task family. The tables are
generated from `healpix_analyse.__all__` and the tool catalogue
(`docs/tools.yaml`); the build fails if a public name is missing. Each name
links to its docstring, generated by sphinx-autoapi from the source (nothing
is imported). The guide of each group explains when to use it.

Documented entry points that are **not exported** from `healpix_analyse`
are listed too, with the module to import them from.

